# ⚡ ECE Toolkit

A lightweight command-line toolkit for common Electronics & Communication Engineering calculations.

## ✨ Features

- **Ohm's Law** — calculate voltage, current, or resistance
- **Power Calculator** — calculate electrical power from voltage and current
- **Frequency Converter** — Hz → kHz → MHz → GHz
- **Resistor Calculator** — calculate resistance from three color bands
- **dBm → Watts** — convert RF power from dBm to watts

## 🚀 Run locally

```bash
python main.py
```

No external dependencies are required.

## 🛠️ Tech Stack

- Python 3
- Command-line interface
- Basic electrical engineering formulas

## 🎯 Why this project?

ECE students frequently switch between engineering formulas and quick unit conversions. ECE Toolkit puts a few everyday calculations into one simple terminal application.
